🛠️ Warum Option 1 in PZ-Lua 100% klappt

Hier ist der Beweis, dass Option 1 exakt so mit den nativen B42-Funktionen gerendert wird:

PZ LUA API

Box-Kacheln: Wir nutzen self:drawRect(x, y, w, h, a, r, g, b) und self:drawRectBorder() in render().

PZ LUA API

Item-Icons: Mit self:drawTextureScaled(getTexture("Item_CarBattery"), x, y, 24, 24, 1, 1, 1, 1) wird das Symbol sauber gezeichnet.

PZ LUA API

Farbiger Ladebalken: Unser neuer Balken nutzt self:drawProgressBar(x, y, w, 22, percent, color) mit grüner, gelber oder roter Farbe je nach Ladezustand.

PZ LUA API

Zusätzliche Ah- & Zeitwerte: Werden per normalem self:drawText(text, x, y, r, g, b, a, font) an festen Spalten-Koordinaten platziert.
